# logging

## ルール
1. 機能のコードで `print()` や `logging` を直接使わない。ログは `backend/app/lib/logger.py` の共通関数を経由する(リクエストIDの付与と、記録する項目の統一を迂回しないため)
2. 記録するのは、外部とのやり取りと失敗しうる処理だけ(FFmpegとffprobeの実行、ディスクの読み書き、アップロードの受け取り)。純粋関数は記録しない
3. エラーは記録したあと必ず再送出する。握りつぶして正常な結果を返さない
4. 入力は要約だけを記録する(動画ID、本数、ファイルサイズ、解像度など)。オブジェクトやファイルの中身を丸ごと渡さない
5. infoを出すのは、FFmpegの実行の成功、1秒を超える処理、重要なイベント(アップロード完了、結合完了)だけ。それ以外の成功は記録しない

## 標準キー
| キー | 内容 |
| --- | --- |
| name | 機能名.関数名の形式(例: `merge.merge_videos`) |
| request_id | リクエスト単位の相関ID |
| video_ids | 関係する動画のID |
| err | 例外の型、メッセージ、スタックトレース |
| ms | 所要時間 |

## FFmpegとffprobeが失敗したとき
- 実行した引数、終了コード、標準エラー出力の末尾を記録する(原因の手がかりは標準エラー出力にある)

## 記録しないもの
- 環境変数の値やAPIキーなどの秘密の値
- 動画ファイルの中身
