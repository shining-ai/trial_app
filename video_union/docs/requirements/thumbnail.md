# 要件定義: 結合リストに動画のサムネイルを表示する

## 背景

結合リストには動画のファイル名・長さ・解像度しか出ないため、撮影日時の名前(`20250804_184201.mp4` など)が並ぶと、どれがどの場面か見分けられない。並べ替えのときに中身を確かめられるよう、各動画の行にサムネイル(縮小画像)を出す。

## ユーザーストーリー(優先度順)

### ストーリー1 — 結合リストで動画の中身を見分ける(P1)
撮影者として、結合リストの各動画の横に、その動画の画像を見たい。
ファイル名だけでは、どの動画がどの場面か分からないから。

受け入れシナリオ:
1. Given 赤一色の動画をアップロードした、When 結合リストに入る、Then その行のファイル名の左に、赤い縮小画像が出る
2. Given 縦長の動画をアップロードした、When 結合リストに入る、Then 縮小画像は縦横の比を保ち、枠の中に収まる
3. Given ffprobe では読めるが先頭のコマを復号できない動画(途中で切れたファイルなど)、When アップロードする、Then 「動画として読み込めませんでした」で失敗し、結合リストに入らない
4. Given サムネイルの画像を読み込めなかった(通信の失敗など)、When 結合リストを見る、Then 画像の代わりに「画像なし」の枠が出て、ほかの操作はふつうにできる

## 機能要件
- FR-001: 結合リストの動画の行に、ファイル名の左にサムネイルを表示すること。テキストの場面の行には表示しない
- FR-002: サムネイルは動画の先頭のコマから作る(表示時の回転を反映する)
- FR-003: 表示の大きさは幅120px程度(枠は 120×68px、16:9)。縦横の比を保って枠に収め、余白は暗い色で埋める
- FR-004: サムネイルはアップロードのときにバックエンドのFFmpegで作り、アップロード済みの動画と同じ場所に保存する。動画を削除したとき、古いファイルを片付けるときに一緒に消す
- FR-005: サムネイルを作れなかった(先頭のコマを復号できない)動画は、結合もできないため、アップロードを「動画として読み込めませんでした」で失敗にし、作ったファイルを残さない。画面でサムネイルの画像を読み込めなかったときは「画像なし」の枠を出す
- FR-006: サムネイルは `GET /api/videos/{id}/thumbnail` で JPEG として返す。ID の形式が正しくない、または見つからないときは 404 を返す

## 成功基準
- SC-001: 赤・緑・青の動画をアップロードすると、結合リストのそれぞれの行に、その色のサムネイルが出ること

## 前提とスコープ外
- アップロードの状況の一覧(「1. 動画を選ぶ」)には表示しない
- 切り出す位置(先頭のコマ)と大きさは選べない
- 次は扱わない
  - サムネイルにマウスを重ねたときのプレビュー再生
  - サムネイルを大きく表示すること
