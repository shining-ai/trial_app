# 要件定義: テキストの場面を動画の間に挟んで結合する

## ユーザーストーリー(優先度順)

### ストーリー1 — 撮影日や場所の見出しを動画の間に挟む(P1)
撮影者として、入力したテキストを黒背景に白文字で表示する場面を、結合する動画の間に挟みたい。
結合した長い動画のどこからが、いつ・どこで撮った動画なのかを、見ている途中でわかるようにするため。

受け入れシナリオ:
1. Given 動画Aと動画Bを結合リストに入れている、When 動画Aと動画Bの間に「2026年10月9日 京都」というテキストの場面を追加して結合する、
   Then ダウンロードした動画は、動画A → 黒背景の中央に白文字で「2026年10月9日 京都」→ 動画B の順に再生される
2. Given テキストの場面を2つ以上、別々の位置に追加した、When 結合する、
   Then それぞれのテキストの場面が、結合リストで指定した位置に表示される
3. Given 改行を含むテキスト(例: 「2026年10月9日」と「京都 嵐山」の2行)を入力した、When 結合する、
   Then 入力どおりの行に分かれて、画面の中央に表示される
4. Given 解像度の違う動画が混ざっている、When テキストの場面を挟んで結合する、
   Then テキストの場面は、動画から決まった出力サイズの黒い画面になり、文字は出力サイズに合わせた大きさで中央に表示される

### ストーリー2 — テキストを表示する時間を決める(P1)
撮影者として、テキストの場面ごとに表示する時間を指定したい。
見出しの長さや読みやすさに合わせて、短すぎず長すぎない時間にするため。

受け入れシナリオ:
1. Given テキストの場面を追加した、When 表示時間を変えない、
   Then 表示時間は3秒になる
2. Given テキストの場面の表示時間に5.5秒を指定した、When 結合する、
   Then ダウンロードした動画で、そのテキストは5.5秒間表示され、その間は無音になる
3. Given テキストの場面の表示時間に1秒未満、または60秒を超える値を入力した、When 確定しようとする、
   Then 受け付けられず、指定できる範囲(1秒〜60秒)が表示される
4. Given 動画とテキストの場面の合計が30分を超える組み合わせになった、When 結合しようとする、
   Then 合計の長さと30分を超えた分の時間が表示され、結合ボタンを押せない

### ストーリー3 — 追加したテキストの場面を直す(P2)
撮影者として、追加したテキストの場面の文言と表示時間をあとから直し、削除や並べ替えもしたい。
結合の前に見出しの誤字や位置の間違いに気づいたとき、作り直さずに済ませるため。

受け入れシナリオ:
1. Given テキストの場面を追加した、When 文言と表示時間を書き換える、
   Then 結合した動画には、書き換えた後の文言が、書き換えた後の時間で表示される
2. Given テキストの場面を追加した、When 動画と同じ操作で並べ替える、
   Then 結合した動画では、並べ替えた後の位置にテキストの場面が表示される
3. Given テキストの場面を追加した、When 動画と同じ操作で削除する、
   Then 結合した動画には、そのテキストの場面が含まれない

## 機能要件
- FR-001: 結合リストに、動画と並べて「テキストの場面」を追加できること
- FR-002: テキストの場面は、結合リストの好きな位置(先頭を含む)に置け、1回の結合にいくつでも入れられること
  - [要確認: 結合リストの末尾(最後の動画の後)にテキストの場面を置くことを認めるか]
  - [要確認: テキストの場面を、既存の「一度に結合できる動画は100本まで」の本数に数えるか]
- FR-003: テキストの場面は、黒い背景の中央に白い文字で表示すること
- FR-004: テキストは改行を含めて入力でき、5行まで、全体で100文字までとすること
  - 上限を超えた入力は、入力の時点で受け付けず、理由を表示する(自動で縮めたり折り返したりしない)
  - 空のテキスト(空白と改行だけのものを含む)は受け付けない
  - [要確認: 文字数に改行を数えるか]
- FR-005: 日本語(ひらがな、カタカナ、漢字)、英数字、一般的な記号を表示できること
- FR-006: 文字の大きさ、位置、書体、太さは利用者が選べないこと。出力サイズに合わせた大きさで、画面の中央に表示する
  - 縦長の出力でも横長の出力でも、5行・100文字までのテキストが画面に収まること
- FR-007: 表示時間はテキストの場面ごとに秒単位で指定でき、小数第1位まで、1秒以上60秒以下、初期値は3秒とすること
  - 範囲外の値や数字でない値は受け付けず、指定できる範囲を表示する
- FR-008: テキストの場面の表示時間は、結合後の長さの上限(30分)に含めて数えること
  - 画面に表示する合計の長さにも含める
- FR-009: テキストの場面の解像度とフレームレートは、動画から決まる出力に合わせること
  - テキストの場面は、出力サイズとフレームレートを決める計算には入れない
- FR-010: テキストの場面の間は無音にすること
- FR-011: 追加したテキストの場面の文言と表示時間を、結合する前に編集できること
- FR-012: テキストの場面の削除と並べ替えは、動画と同じ操作でできること
- FR-013: 結合するには、結合リストに動画が1本以上あること。テキストの場面だけでは結合できない
  - [要確認: 既存の「結合できるのは2本以上」の条件に、テキストの場面を数えるか(例: 動画1本+テキストの場面1つで結合できるか)]
- FR-014: 入力したテキストの内容と表示時間は、画面での確認に加え、結合を受け付ける時点でも必ず確認すること

## 成功基準
- SC-001: 動画2本の間にテキストの場面を1つ挟んで結合すると、ダウンロードした動画が「動画 → テキストの場面 → 動画」の順に最後まで再生できること
- SC-002: ダウンロードした動画で、テキストの場面が黒背景に白文字で表示され、入力した文言(日本語と改行を含む)をそのまま読めること
- SC-003: ダウンロードした動画で、テキストの場面の長さが指定した表示時間と0.1秒以内の差で一致すること
- SC-004: 1920x1080 と 1080x1920 の動画を混ぜた結合で、5行・100文字のテキストの場面が、出力の画面からはみ出さずに表示されること
- SC-005: 表示時間に0.9秒、60.1秒、数字でない値を指定したとき、またはテキストが101文字・6行・空のとき、どれも受け付けられず理由が表示されること
- SC-006: 動画とテキストの場面の合計が30分を超えるとき、結合できず、超えた分の時間が表示されること

## 前提とスコープ外
- 利用者は作成者本人の1人
- テキストの場面は「動画の間に挟む見出し」であり、動画の上に文字を重ねる字幕とは別物として扱う(字幕は引き続きスコープ外)
- 動画の結合、上限、出力形式、ファイルの扱いは `video-merge.md` の要件に従う
- 次は扱わない
  - 文字の大きさ、位置、書体、色、背景色を利用者が選ぶこと
  - フェードイン・フェードアウトなどの演出
  - 絵文字の表示
  - 結合前にテキストの場面を画面で確認すること(プレビュー)
  - 動画を含まない、テキストの場面だけの動画を作ること
- `docs/product.md` の「主要な機能」への追記は今回は行わない
