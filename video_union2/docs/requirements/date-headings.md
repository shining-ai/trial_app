# 要件定義: 撮影日時の順に並べ、撮影日ごとに見出しを入れる

## 背景

プロトタイプ(`video_union/src/concat.py`)は、撮影日時のファイル名(例: `20250804_184201.mp4`)の順に動画を並べ、撮影日が変わるたびに日付の見出しを挟んで、1か月分(10〜42本、撮影日7〜18日)の動画を1本にまとめていた。今のアプリでは、アップロードは終わった順に一覧へ入り、見出しは1つずつ手で入れる必要がある。プロトタイプでできていたこの作業を、画面のボタンでできるようにする。

## ユーザーストーリー(優先度順)

### ストーリー1 — 撮影日時の順に並べる(P1)
撮影者として、アップロードした動画を、ボタン1つで撮影日時の順に並べたい。
アップロードは終わった順に一覧へ入るので、1か月分を手で並べ直すのは手間だから。

受け入れシナリオ:
1. Given `20250805_120000.mp4`・`20250804_090000.mp4`・`20250804_180000.mp4` をこの順で一覧に入れている、When 「撮影日時の順に並べる」を押す、
   Then 並びは `20250804_090000.mp4`・`20250804_180000.mp4`・`20250805_120000.mp4` になる
2. Given 動画の直前に見出し(テキストの場面)がある、When 並べる、Then 見出しはその動画の直前についたまま一緒に動く
3. Given ファイル名から撮影日時を読めない動画(例: `clip.mp4`)がある、When 並べる、Then その動画は末尾に、元の順のまま並ぶ

### ストーリー2 — 撮影日ごとに見出しを入れる(P1)
撮影者として、ボタン1つで、撮影日が変わるたびにその日付の見出しを入れたい。
1か月で十数個の見出しを1つずつ入力するのは手間だから。

受け入れシナリオ:
1. Given `20250804_090000.mp4`・`20250804_180000.mp4`・`20250805_120000.mp4` がこの順で並んでいる、When 「撮影日ごとに見出しを入れる」を押す、
   Then 「2025年8月4日」・2本の動画・「2025年8月5日」・1本の動画、の順になり、見出しの表示時間は1秒になる
2. Given 見出しを入れたあと、When もう一度押す、またはあとから同じ日の動画を足して並べ直してから押す、Then 見出しは増えない(同じ日付の見出しがすでにあれば、新しく作らずにその日の最初の動画の前へ移す)
3. Given 撮影日時を読めない動画がある、When 押す、Then その動画には見出しを付けない

## 機能要件
- FR-001: 結合リストの動画を、ファイル名から読んだ撮影日時の古い順に並べるボタンを設けること
- FR-002: 撮影日時は、ファイル名の中の「8桁の日付 + `_` または `-` + 6桁の時刻」(例: `20250804_184201`、`VID_20250804_184201.mp4`、`PXL_20250804_184201123.mp4`)から読む。日付として正しくない値(13月など)は読めないものとして扱う
- FR-003: 並べるとき、テキストの場面は、すぐ後ろの動画の見出しとして、その動画と一緒に動かす。最後の動画より後ろのテキストの場面は、末尾のまま残す。ただし日付の見出し(動画に出てくる撮影日と同じ文のテキストの場面)は「その日の見出し」として、その日の最初の動画の前へ置き直す(並べるだけでは新しく作らない)
- FR-004: 撮影日時を読めない動画は、読めた動画の後ろに、元の順のまま並べる。撮影日時が同じ動画は、元の順のまま並べる
- FR-005: 撮影日が変わるたびに、その日の最初の動画の直前へ、日付の見出し(「2025年8月4日」の形、表示時間1秒)を入れるボタンを設けること。並びは変えない(撮影日時の順に並べてから押す使い方を想定する)
- FR-006: 同じ日付の見出しがすでにあるときは、新しく作らずにその見出しをその日の最初の動画の前へ移す(表示時間など直した内容は保つ)。同じ日付の見出しが2つ以上あれば1つにまとめる(何度押しても、あとから動画を足して押し直しても、見出しが増えない)
- FR-007: 撮影日時を読めない動画には見出しを付けない
- FR-008: 入れた見出しは、手で入れた見出しと同じく、編集・削除・並べ替えができること
- FR-009: 入力欄が開いている間と結合中は、2つのボタンを押せないこと。結合リストに動画がないときも押せないこと
- FR-010: 入れた見出しの表示時間も、結合後の長さ(30分まで)に数えること(既存の FR と同じ)

## 成功基準
- SC-001: 撮影日時がばらばらの順にアップロードした3本の動画を、ボタン1つで撮影日時の順に並べ、そのまま結合した動画がその順になっていること
- SC-002: 「撮影日ごとに見出しを入れる」を押して結合すると、撮影日が変わる位置に日付の見出しの場面が入った動画になること
- SC-003: 見出しを入れるボタンを2回押しても、見出しが増えないこと

## 前提とスコープ外
- 撮影日時はファイル名からだけ読む。動画の中の撮影日時の情報(メタデータ)は読まない
- 見出しの文の形(「2025年8月4日」)と表示時間(1秒)は選べない(入れたあとに1つずつ編集はできる)
- 次は扱わない
  - 新しい順(降順)に並べること
  - 出力のファイル名を決めること(ダウンロードしたあとに名前を変える)
  - 撮影日ごとではない区切り(月・週ごと)の見出し
