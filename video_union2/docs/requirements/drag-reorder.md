# 要件定義: ドラッグで結合リストの順番を並べ替える

## ユーザーストーリー(優先度順)

### ストーリー1 — ドラッグで並べ替える(P1)
撮影者として、結合リストの動画とテキストの場面を、つかんで目的の位置まで動かして並べ替えたい。
動画が多いと、「上へ」「下へ」のボタンを何度も押して動かすのが手間だから。

受け入れシナリオ:
1. Given 結合リストに動画A・B・Cがある、When Cのつまみをつかんで A の上まで動かして離す、
   Then 並びは C・A・B になり、結合するとその順でつながった動画になる
2. Given 動画AとBの間にテキストの場面Tがある、When Tのつまみをつかんで B の下まで動かして離す、
   Then 並びは A・B・T になる
3. Given 動画をつかんで動かしている、When 一覧の外で離す、または Esc キーを押す、
   Then 並びは動かす前のまま変わらない
4. Given 動かしている間、Then 動かしている行と、離すと入る位置が画面でわかる

### ストーリー2 — キーボードやスマホでも並べ替える(P2)
撮影者として、マウスがない場面(キーボードだけ、スマホ)でも同じように並べ替えたい。
どの環境でも同じ操作で順番を決められるようにするため。

受け入れシナリオ:
1. Given つまみにキーボードで移動している、When スペースキーでつかみ、矢印キーで動かし、スペースキーで置く、
   Then その位置に並べ替わり、つかんだ・動かした・置いたことが日本語で読み上げられる
2. Given スマホで結合リストを見ている、When つまみを長押ししてから指を動かして離す、
   Then その位置に並べ替わる。長押しせずに指を動かしたときは、画面がスクロールするだけで並びは変わらない

## 機能要件
- FR-001: 結合リストの動画とテキストの場面を、ドラッグで任意の位置(先頭・末尾を含む)へ動かせること
- FR-002: ドラッグは各行の「つまみ」をつかんで行うこと。行の中のボタンや文字の上からはドラッグを始めない
- FR-003: ドラッグ中は、動かしている行と、離すと入る位置がわかるように表示すること
- FR-004: 一覧の外で離したとき、または Esc キーを押したときは、並びを変えないこと
- FR-005: キーボードでも並べ替えられること(スペースキーでつかむ・矢印キーで動かす・スペースキーで置く・Esc キーで取り消す)。つかんだ・動かした・置いた・取り消したことを日本語で読み上げること
- FR-006: タッチ操作では、つまみの長押しでドラッグを始めること(長押しでない指の動きはスクロールとして扱う)
- FR-007: 入力欄が開いている間と結合中は、ドラッグで並べ替えられないこと(「上へ」などのボタンと同じ)
- FR-008: 一覧が画面より長いときは、ドラッグ中に画面の端へ近づくと一覧がスクロールすること
- FR-009: 既存の「上へ」「下へ」「先頭へ」「末尾へ」のボタンは残すこと
- FR-010: ドラッグで並べ替えた結果は、ボタンで並べ替えたときと同じく、合計の長さと結合の順番に反映されること

## 成功基準
- SC-001: 動画3本の一覧で、末尾の動画を先頭へドラッグして結合すると、ダウンロードした動画がその順になっていること
- SC-002: テキストの場面を動画の後ろへドラッグして結合すると、ダウンロードした動画でその位置に見出しが表示されること
- SC-003: 一覧の外で離した・Esc キーを押したときに、並びが変わらないこと
- SC-004: キーボードだけで(マウスを使わずに)並べ替えができ、読み上げの文言が日本語であること
- SC-005: 入力欄が開いている間・結合中は、ドラッグしても並びが変わらないこと

## 前提とスコープ外
- 利用者は作成者本人の1人。並べ替えの対象は結合リストの中だけ
- ドラッグできるのは結合リストの並び順だけで、サーバーの処理は変えない
- 次は扱わない
  - ファイルを画面にドラッグ&ドロップしてアップロードすること
  - 複数の行をまとめて選んで動かすこと
  - アップロードの状況の一覧の並べ替え
- `docs/requirements/video-merge.md` のスコープ外にあった「ドラッグ&ドロップでの並べ替え」は、この要件で扱う
