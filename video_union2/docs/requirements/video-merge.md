# 要件定義: 動画のアップロードから結合、ダウンロードまで

## ユーザーストーリー(優先度順)

### ストーリー1 — 複数の動画を1本に結合する(P1)
撮影者として、撮りためた複数の動画をアップロードして順番を決め、
1本の長い動画としてダウンロードしたい。動画を1本にまとめて整理するため。

受け入れシナリオ:
1. Given 動画ファイルが複数ある、When アップロードして順番を決め、結合する、
   Then 指定した順番でつながった1本の動画をダウンロードできる
2. Given 解像度が違う動画が混ざっている(例: 1920x1080 と 1080x1920)、When 結合する、
   Then 出力は幅と高さそれぞれの最大値(例では 1920x1920)になり、
   小さい動画は拡大されずに中央に置かれ、余白は黒で埋まる
3. Given 結合後の長さが30分を超える組み合わせを指定した、When 結合する、
   Then 合計の長さと30分を超えた分の時間が表示され、結合ボタンを押せない

## 機能要件
- FR-001: 複数の動画ファイルをアップロードできること
- FR-002: アップロードした動画の結合順を、利用者が決められること
- FR-003: 指定した順番で、動画を1本に結合すること
- FR-004: 結合した動画をファイルとしてダウンロードできること
- FR-005: 形式や解像度が違う動画が混ざっていても結合できること
- FR-006: 出力の幅は全動画の幅の最大値、高さは全動画の高さの最大値にすること
  (例: 1920x1080 と 1080x1920 なら 1920x1920)
- FR-007: 出力より小さい動画は拡大せず、中央に配置し、縁を黒で埋めること
- FR-008: 次の上限を超える入力は受け付けないこと(暫定値。正式な値は未定)
  - 一度に結合できる動画は100本まで
  - 1本あたりの解像度は4K(3840x2160。縦長は2160x3840)まで
  - 1本あたりのファイルサイズは4GBまで
  - 結合後の動画の長さは30分まで
- FR-009: 上限を超えたときは、次の時点で知らせること。画面での確認に加え、サーバーでも必ず確認する
  - ファイルサイズ(4GB): ファイルを選んだ時点で画面が確認し、超えたファイルはアップロードせず、一覧のそのファイルに理由を表示する。サーバーも受信中に4GBを超えたら打ち切り、HTTP 413 を返す
  - 解像度(4K): アップロード直後にサーバーが ffprobe で調べ、超えたファイルだけを失敗にして理由を表示する(例: 「解像度 7680x4320 は上限 3840x2160 を超えています」)。他のファイルのアップロードは続ける
  - 本数(100本): 101本目は画面で追加できないようにし、上限に達したことを表示する
  - 結合後の長さ(30分): 並べ替え・追加・削除のたびに画面が合計の長さを表示し、30分を超えたら結合ボタンを押せないようにして、超えた分の時間を表示する
  - 本数と結合後の長さは、結合リクエストを受けた時点でサーバーも確認し、超えていれば HTTP 422 と理由を返す
  - 画面で合計の長さを出せるよう、アップロードの応答に各動画の長さ・幅・高さを含める
- FR-010: 出力ファイルの形式は MP4(映像 H.264、音声 AAC)とすること
  - 画素形式は yuv420p とし、先頭に再生情報を置く(faststart)
  - 出力の幅・高さが奇数になるときは、偶数に切り上げる(例: 1919x1079 → 1920x1080)
- FR-011: フレームレートが違う動画が混ざったときは、入力のうち最も高いフレームレート(上限60fps)に揃えること
  - 低いフレームレートの動画はフレームを複製して合わせる
  - 可変フレームレートの動画も固定フレームレートに揃える
- FR-012: 音声のない動画が混ざったときは、その動画の長さぶんの無音を入れること
  - 出力には常に音声トラックを持たせる(全動画に音声がない場合も無音のトラックを付ける)
  - 音声は 48kHz・ステレオに揃える
- FR-013: 動画でないファイルは、アップロード時にサーバーが ffprobe で判定して拒否すること
  - 拡張子や MIME タイプでは判定しない。画面の `accept="video/*"` は選びやすくするためだけに使う
  - 動画と認める条件: 映像ストリームがある、長さが取れて0秒より長い、静止画の形式ではない
  - 条件を満たさないファイルは保存したものを削除し、HTTP 422 を返す。画面ではそのファイルだけに「動画として読み込めませんでした」と表示し、他のファイルは続ける

## 成功基準
- SC-001: 複数の動画ファイルが結合され、1本の動画ファイルとしてダウンロードできること
- SC-002: ダウンロードした動画が、指定した順番どおりに最後まで再生できること

## 前提とスコープ外
- 利用者は作成者本人の1人
- ログインやユーザーごとのデータの区別は扱わない
- 動画の編集(カット、字幕、音量調整など)は扱わない
